# 个人论文卡片系统

这个目录把自动论文 Feed 变成可执行的科研输入。目标不是每天收藏很多论文，而是每天消化一篇，并让阅读改变一个研究决定。

## 每周节奏

| 时间 | 任务 | 交付物 |
| --- | --- | --- |
| 周一至周五 | 从当日候选中筛三篇、精读一篇 | 一张个人论文卡片 |
| 周六 | 不增加新论文，回看本周五张卡片 | 一份周复盘和一个下周实验问题 |
| 周日 | 休息 | 无 |

单日建议用时为 60 至 90 分钟：10 分钟筛选、35 至 50 分钟结构化阅读、15 至 20 分钟填写卡片、5 至 10 分钟确定下一步。

## 人机边界

自动任务可以填写：论文元数据、公开链接、任务设定、作者报告的关键结果、建议重点查看的图表与页码。

以下内容必须本人填写，自动任务不得代写：

- 我的一句话总结；
- 问题、缺口与核心挑战；
- 我重画的方法流程；
- 最强证据及其不能证明的内容；
- 最大弱点或替代解释；
- 对火灾/极端环境主线的迁移假设；
- 24 小时内要完成的动作。

## 文件约定

- 日卡片：`paper-cards/YYYY/MM/YYYY-MM-DD-short-title.md`
- 周复盘：`paper-cards/weekly/YYYY-Www.md`
- 自绘配图：`paper-cards/assets/YYYY/MM/DD/`

优先使用 GitHub 可直接渲染的 Mermaid 自绘方法图。需要引用论文原图时，先链接官方论文页并注明图号、来源和版权；不要默认把论文图片复制到公开仓库。

## 完成标准

一张卡片只有同时满足以下条件才算完成：

- 能不看摘要说清问题、核心机制和关键证据；
- 画出了输入到输出的主流程；
- 指出了至少一个证据边界或可能的替代解释；
- 写下了一个可证伪的迁移假设；
- 安排了一个 24 小时内可以完成的动作。

状态依次使用：`inbox -> read -> converted -> reproduced`。没有转化动作的卡片最多停留在 `read`。
