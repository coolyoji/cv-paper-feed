1. **Repurposing Stable Diffusion Attention for Training-Free Unsupervised Interactive Segmentation**
   - Source: CVPR 2025, 2025
   - Authors: Markus Karmann, Onay Urfalioglu
   - Tags: interactive segmentation, training-free, Stable Diffusion attention, Markov map
   - Links: [paper](https://openaccess.thecvf.com/content/CVPR2025/html/Karmann_Repurposing_Stable_Diffusion_Attention_for_Training-Free_Unsupervised_Interactive_Segmentation_CVPR_2025_paper.html) / [pdf](https://openaccess.thecvf.com/content/CVPR2025/papers/Karmann_Repurposing_Stable_Diffusion_Attention_for_Training-Free_Unsupervised_Interactive_Segmentation_CVPR_2025_paper.pdf)
   - 论文：Repurposing Stable Diffusion Attention for Training-Free Unsupervised Interactive Segmentation
   - 一句话总结：M2N2把Stable Diffusion自注意改写成马尔可夫到达步数图，再用点击引导的截断最近邻完成无训练交互分割。
   - 任务设定：输入自然图像及用户逐次给出的前景/背景点击，输出二值实例掩码；不使用分割标签、不训练新网络，依赖冻结SD2自注意提供语义距离。
   - 摘要详解：论文针对无监督交互分割仍需伪标签训练、原始注意图噪声大且难分实例的问题。M2N2以空文本提示对无噪编码潜变量做一次去噪前向，聚合SD2高分辨率自注意并视为马尔可夫转移矩阵；从每个点击出发迭代概率状态，以达到相对阈值所需步数形成Markov-map，再用改造的flood fill压制局部极小值。各点击图经先验、边缘和正负点击一致性选择截断阈值，最近邻给出前景或背景。GrabCut的NoC85/90为1.62/1.90，DAVIS为4.60/6.72，较MIS少1.73/1.72次点击；去掉flood fill则为5.50/7.42，支持该模块的整体贡献，但不能单独证明实例分离机制。BraTS在10次点击时IoU仅70%，显示SD2的自然图像域偏差。
   - 实验结论：四个自然图像数据集上，M2N2在三组无监督比较中最佳；去掉flood fill或只用原始注意都会增加点击数，但医学域结果明显落后监督模型。
   - 和我课题的关系：COD可检验Markov-map能否把弱纹理差积累成边界；UAV小目标可能在低分辨率注意中消失；火烟的形状随时间变化，静态点击距离不能直接表示火情。
   - 可借鉴点：把注意转成可达性而非直接阈值；用前景/背景点击一致性自适应截断语义距离。
   - 可改进点：在COD、UAV与早烟数据上按目标面积分层比较原始注意、Markov-map及高分辨率特征；若小目标或透明烟雾无增益，应否定“迭代必然增强弱证据”。
   - 是否值得精读：值得，式（1）至（11）把点击、马尔可夫迭代、阈值选择和最终分割连成完整可检验链条。

2. **CDICS: Delving Into Fine-Grained Attribute for In-Context Segmentation via Compositional Prompts and Phased Decoupling**
   - Source: CVPR 2026, 2026
   - Authors: Zhiyu Li, Dianmo Sheng, Qi Chu, Shilong Chen, Tao Gong et al.
   - Tags: in-context segmentation, compositional prompt, part and color, fine-grained segmentation
   - Links: [paper](https://openaccess.thecvf.com/content/CVPR2026/html/Li_CDICS_Delving_Into_Fine-Grained_Attribute_for_In-Context_Segmentation_via_Compositional_CVPR_2026_paper.html) / [pdf](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_CDICS_Delving_Into_Fine-Grained_Attribute_for_In-Context_Segmentation_via_Compositional_CVPR_2026_paper.pdf)
   - 论文：CDICS: Delving Into Fine-Grained Attribute for In-Context Segmentation via Compositional Prompts and Phased Decoupling
   - 一句话总结：CDICS先按语义找出候选实例，再用部件与颜色组合提示精化外观，以降低一次融合造成的属性干扰。
   - 任务设定：输入目标图像及可拆分的语义参考、部件参考和颜色值，输出满足组合属性的语义/实例掩码；训练依赖组合任务监督，推理按给定视觉提示指定属性。
   - 摘要详解：论文指出单个参考图难覆盖稀有属性组合，已有视觉上下文分割又多停留在类别或实例层面。CDICS用DINOv2编码目标、语义参考和部件参考，以目标图像像素和参考色的CIEDE2000色差生成相似图，再经FiLM调制目标特征。第一阶段仅用语义原型和实例查询粗定位；第二阶段以候选区域加权目标特征，由Appearance Fusion依次结合颜色、部件和语义信息，输出满足组合约束的掩码。训练数据正负样本约为3:1，负样本要求输出空掩码。ColorPACO的IoU/FPR为57.6%/3.9%，ColorPartImageNet为84.4%/12.5%，COCO-20i IoU为65.2%。消融中完整模型的IoU/AP50由基线50.3%/27.7%升至58.9%/42.4%；主比较中的ColorPACO AP50为34.9%，两套数值不可混用。
   - 实验结论：组合提示在ColorPACO显著降低错误激活，且COCO-20i性能未明显牺牲；不过两个重构数据集、精确颜色标注和单一训练配方限制外部有效性。
   - 和我课题的关系：COD可把类别、边界部件和局部色差分阶段处理；UAV目标过小时部件提示可能失效；火烟没有稳定部件和颜色，需把外观提示改成时序增长与热信号。
   - 可借鉴点：先解决目标存在与粗定位，再施加细属性约束；用无匹配提示的FPR检验模型是否服从条件。
   - 可改进点：构造同类别近色、错部件及空目标对照，比较一次融合与两阶段的IoU、FPR和校准；若优势只在人工颜色值下成立，组合解释不能泛化。
   - 是否值得精读：值得，方法式（1）至（8）连接颜色相似、两阶段加权、外观融合和损失；式（9）仅定义评测FPR。

3. **Uncertainty-Aware Vision-Language Segmentation for Medical Imaging**
   - Source: WACV 2026, 2026
   - Authors: Aryan Das, Tanishq Rachamalla, Koushik Biswas, Swalpa Kumar Roy, Vinay Kumar Verma
   - Tags: vision-language segmentation, uncertainty, medical imaging, state-space model
   - Links: [paper](https://openaccess.thecvf.com/content/WACV2026/html/Das_Uncertainty-Aware_Vision-Language_Segmentation_for_Medical_Imaging_WACV_2026_paper.html) / [pdf](https://openaccess.thecvf.com/content/WACV2026/papers/Das_Uncertainty-Aware_Vision-Language_Segmentation_for_Medical_Imaging_WACV_2026_paper.pdf)
   - 论文：Uncertainty-Aware Vision-Language Segmentation for Medical Imaging
   - 一句话总结：该方法先做视觉自注意，再以状态空间混合后的文本做交叉注意；卷积式多尺度解码后，用Dice、频谱差和低熵正则共同训练。
   - 任务设定：输入放射或内镜图像及对应临床文本，输出像素级病灶掩码；训练有掩码与文本，推理默认文本可用。单次预测熵只作低熵正则，模型不输出后验方差。
   - 摘要详解：论文针对医学分割在低质量影像下易失真、视觉语言方法又少验证预测歧义的问题。ConvNeXt-Tiny提取四级视觉特征，冻结BioViL CXR-BERT编码文本；每级MoDAB先做视觉自注意，再以视觉查询对SSMix混合后的文本做交叉注意。融合特征经转置卷积、跳连CRB和SUN逐级恢复掩码，SEU目标相加Dice、傅里叶幅度差与单次预测熵。作者报告QATA-COVID19 Dice/mIoU为92.24%/84.90%，MosMed++为79.67%/66.38%，Kvasir-SEG为93.83%/87.62%；推理去文本时Kvasir Dice降至87.28%，去MoDAB降至85.15%。替换SSMix和交叉注意也会下降，但论文没有分别去掉频谱项与熵项，也没有报告ECE、Brier或风险覆盖曲线，不能把增益归因于校准，跨域可靠性尚未证明。
   - 实验结论：三个数据集支持文本融合与完整组合的贡献，Kvasir去掉MoDAB降到85.15 Dice；但熵变小只表示输出更尖锐，并不能单独证明概率已校准或风险可控。
   - 和我课题的关系：COD可把预测熵作为前景背景混淆的复核信号，UAV可标记小目标弱证据，火烟可触发复核；三者都需校准，不能把低熵等同正确。
   - 可借鉴点：把单次预测熵作为可消融的训练正则；在多尺度视觉解码时用文本提供语义条件。
   - 可改进点：加入ECE、Brier、risk-coverage及跨域缺文本/错文本测试，并与纯熵最小化等参数模型对照；若低熵却误检增加，应否定可靠性主张。
   - 是否值得精读：值得，式（1）至（29）覆盖编码、注意、状态空间混合、卷积解码、谱正则和熵正则，适合核查不确定性是否被真正建模。

4. **Active Learning Meets Foundation Models: Fast Remote Sensing Data Annotation for Object Detection**
   - Source: ICCV 2025, 2025
   - Authors: Marvin Burges, Philipe Ambrozio Dias, Carson Woody, Sarah Walters, Dalton Lunga
   - Tags: remote sensing, active learning, SAM, object detection, annotation efficiency
   - Links: [paper](https://openaccess.thecvf.com/content/ICCV2025/html/Burges_Active_Learning_Meets_Foundation_Models_Fast_Remote_Sensing_Data_Annotation_ICCV_2025_paper.html) / [pdf](https://openaccess.thecvf.com/content/ICCV2025/papers/Burges_Active_Learning_Meets_Foundation_Models_Fast_Remote_Sensing_Data_Annotation_ICCV_2025_paper.pdf)
   - 论文：Active Learning Meets Foundation Models: Fast Remote Sensing Data Annotation for Object Detection
   - 一句话总结：AL4FM-OD用SAM掩码与检测框的不一致挑困难图，再按掩码特征去冗余，并在冷启动时以SAM框替换差定位。
   - 任务设定：输入少量已标注与大量未标注遥感图像，在固定查询预算下循环选择、半自动标注并微调检测器；假设SAM能给多数目标提供可用候选掩码。
   - 摘要详解：论文针对遥感目标检测主动学习中分类与定位可靠性不能由单一置信度刻画、冷启动框偏差又大的问题。AL4FM-OD先离线缓存SAM密集掩码和框；每轮将其与RT-DETRv2框做忽略类别的匈牙利匹配，以匹配质量和检测置信度的调和均值补量作为对象不确定性。对象分数在图内取均值后，选出六倍预算的候选。MDE再用掩码内基础模型特征建立每类五个原型，对候选做对象级多样性重排；DBS保留类别、以重叠最大的SAM框辅助人工。DIOR最后一轮为10.68，对PPAL 4.89；DOTAv2为7.93，低于PPAL 9.24，说明小目标SAM漏检会限制收益。
   - 实验结论：DIOR、HRSC2016和WaffleHomes支持采样收益，DOTAv2与FAIR1M并非最佳。八人一小时研究的表6给出AP50 0.34对0.28、AP75 0.17对0.11、AR100 0.43对0.35；正文所写14%、3%、8%与表值不一致，故只保留表值，不替作者重算。
   - 和我课题的关系：UAV/遥感可直接采用预算式标注；COD中SAM可能漏掉伪装目标；早期烟雾无清晰边界，必须允许无框候选和时序查询，不能照搬框切换。
   - 可借鉴点：把基础模型与任务模型的不一致作为查询信号；先筛困难图，再用掩码内对象原型去冗余。
   - 可改进点：让所有采样基线共享同一骨干与SAM预标，按尺寸统计未匹配框和每预算AP；若采样优势在控制SAM资源后消失，或随SAM漏检同步下降，就不能归因于主动策略。
   - 是否值得精读：值得，但主方法只有式（1）是编号公式；匹配质量变换未编号，MDE与DBS仅有流程图和文字规则，需结合代码核对，不能宣称存在六个连续编号式。

5. **Finding Dino: A Plug-and-Play Framework for Zero-Shot Detection of Out-of-Distribution Objects Using Prototypes**
   - Source: WACV 2025, 2025
   - Authors: Poulami Sinhamahapatra, Franziska Schwaiger, Shirsha Bose, Huiyu Wang, Karsten Roscher et al.
   - Tags: zero-shot OOD, prototype, DINOv2, open-world detection, anomaly segmentation
   - Links: [paper](https://openaccess.thecvf.com/content/WACV2025/html/Sinhamahapatra_Finding_Dino_A_Plug-and-Play_Framework_for_Zero-Shot_Detection_of_Out-of-Distribution_WACV_2025_paper.html) / [pdf](https://openaccess.thecvf.com/content/WACV2025/papers/Sinhamahapatra_Finding_Dino_A_Plug-and-Play_Framework_for_Zero-Shot_Detection_of_Out-of-Distribution_WACV_2025_paper.pdf)
   - 论文：Finding Dino: A Plug-and-Play Framework for Zero-Shot Detection of Out-of-Distribution Objects Using Prototypes
   - 一句话总结：PROWL用少量已知类样例构建冻结DINOv2原型库，以像素相似度找未知区域，再用无监督前景掩码抑制背景误报。
   - 任务设定：给定运行域内的已知类别清单和每类少量分割样例，测试任意场景时定位不属于已知类的对象；不在目标域训练或微调模型。
   - 摘要详解：论文针对开放世界中未知对象与普通背景难区分、监督异常分割又依赖目标域训练的问题。PROWL离线用冻结DINOv2提取已知类实例的掩码内特征，经空间平均后把每个实例保留为独立原型；测试时取每个像素与所有已知原型的最大余弦相似度，反相分数超过阈值即视为OOD。为减少背景像素误报，方法再接STEGO或CutLER前景掩码，以掩码内多数投票判定完整实例。PROWL+CutLER在RoadAnomaly的AUPR/FPR95为75.25%/1.75%，RoadObstacle为73.53%/5.58%；铁路与海事二值IoU为83.29%和73.30%。vanilla PROWL在铁路IoU仅8.01，显示前景掩码主导该域结果；约十五个原型后趋于饱和，但远距小障碍仍困难。
   - 实验结论：道路、铁路和海事结果支持无需梯度更新的跨域可用性，且前景掩码显著降低背景误报；不过建库仍需实例掩码，阈值靠验证集，跨域基准也不统一。
   - 和我课题的关系：COD可把正常背景模式当已知原型，UAV可检测未知小目标；火烟与背景连续混合且形态变化，单原型阈值易把云雾或霞光误判。
   - 可借鉴点：先做类别原型距离，再用对象性掩码约束空间连续性；把未知检测与背景抑制分成两个可消融环节。
   - 可改进点：比较类别均值、实例多原型和尺度条件原型，并固定阈值跨数据集测试；若优势依赖逐域调阈或CutLER召回，就不能声称无需适配。
   - 是否值得精读：值得，式（1）至（5）清楚定义原型构造、像素匹配和逆相似度，实验也直接暴露小目标与背景混淆边界。
