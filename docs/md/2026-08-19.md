1. **Cross Modal Fine-Grained Alignment via Granularity-Aware and Region-Uncertain Modeling**
   - Source: AAAI 2026, 2026-03-14

   - Tags: fine-grained image-text alignment, VLM/MLLM, grounded vision, uncertainty/calibration, retrieval/prototype
   - Links: [paper](https://ojs.aaai.org/index.php/AAAI/article/view/39544) / [pdf](https://ojs.aaai.org/index.php/AAAI/article/download/39544/43505)
   - 论文：Cross Modal Fine-Grained Alignment via Granularity-Aware and Region-Uncertain Modeling
   - 一句话总结：GRM 先在图像和文本各自内部筛关键 token，再用重叠区域提示与区域高斯表达一对多歧义，并以三层双向检索监督完成细粒度对齐。
   - 任务设定：输入一张图像和一句描述，ViT 或 Swin 产生 patch token，BERT 产生 word token；模型输出图找文和文找图的匹配分数。区域由可学习提示软聚合，没有框、掩码或局部歧义标注，训练监督来自配对图文与难负样本。
   - 摘要详解：研究问题：细粒度图文检索既要判断哪些 patch 与词元关键，又要表达一词多区域、一区域多词的局部歧义；普通跨模态注意力受检索损失间接驱动，且通常只给确定向量。方法与流程：GRM 用视觉 significance-aware 与文本 granularity-aware 两个 Gumbel-Softmax 适配器做模态内软筛选；多个可学习提示以 sigmoid 亲和度聚合可重叠区域，再预测对角高斯的均值和方差并重参数化采样。系统在原始、筛选、随机区域三层计算双向对比排序损失，另加重建、KL 与区域熵正则。实验结论：ViT-224+BERT 在 Flickr30K、COCO 1K、COCO 5K 的 rSum 为 516.2、532.5、443.0，均高于 AVSE；去掉 SA、GA、区域提示或不确定性后，Flickr30K rSum 分别降至 502.8、507.0、503.3、508.3。这说明分支具有互补性，但尚未排除额外容量和多重监督的影响。边界：论文没有校准指标、完整总损失系数或推理采样规则，因此只能证明多粒度建模改善检索，不能证明方差就是可靠风险。
   - 实验结论：作者在 Flickr30K 和 MS-COCO 报告双向 R@1、R@5、R@10 与 rSum。ViT-224+BERT 的三个 rSum 为 516.2、532.5、443.0，Swin-384 为 550.7、548.0、478.3；表 2 和表 3 显示 token 门、区域提示及三层对比目标均有贡献。热图只能作为定性线索，论文未用区域真值或校准指标验证提示和方差。
   - 和我课题的关系：COD：区域提示可并行表示伪装前景、背景和边界，但检索级监督不保证连通掩码，高方差也不等于边界错误。UAV：多提示能表达同类密集实例，区域不确定性却无法恢复下采样前已消失的微小像素。火灾：烟雾可对应多个半透明区域，云雾霾等又形成语义近邻；静态图文高斯缺少增长、漂移、可见光与热红外一致性，不能直接承担早期报警。
   - 可借鉴点：把模态内 token 门控、重叠区域提示和区域级不确定性移到高分辨率弱证据特征层，并保留原始、筛选、随机区域三条监督路径。COD 可测试方差是否集中于真实错误边界；UAV 可让尺度提示决定局部放大或请求更高分辨率；火灾可把 RGB、热像与连续帧区域作为不同 token 集，再加入时序一致性。
   - 可改进点：先用参数匹配的确定性多区域分支和仅增加三层损失的基线排除容量解释，再报告区域 NLL、风险覆盖率、推理重复方差与成本。COD 在 COD10K/CAMO 到 NC4K 上测掩码和边界；UAV 在 VisDrone/UAVDT 按尺寸、遮挡、模糊测 AP_S 与校准；火灾加入云、雾、霾、夕阳和反光硬负例，测固定误报下召回与报警提前量。若方差不能排序真实错误，就应放弃风险语义。
   - 是否值得精读：值得。论文把 token 筛选、重叠区域发现和局部概率表示连成可追踪的数据流，式 (1)-(13) 与消融足以支撑方法学习；但区域可解释性、方差校准、总目标和推理采样仍未证实，迁移时必须设置确定性容量对照。

2. **Open-World Hazard Detection and Captioning for Autonomous Driving with a Unified Multimodal Pipeline**

   - Authors: Parisa Hatami, Maged Shoman, Mina Sartipi
   - Tags: safety-critical/hazard, open-world, VLM/MLLM, depth/geometry, video, degraded perception
   - Links: [paper](https://openaccess.thecvf.com/content/WACV2025W/COOOL/html/Hatami_Open-World_Hazard_Detection_and_Captioning_for_Autonomous_Driving_with_a_WACVW_2025_paper.html) / [pdf](https://openaccess.thecvf.com/content/WACV2025W/COOOL/papers/Hatami_Open-World_Hazard_Detection_and_Captioning_for_Autonomous_Driving_with_a_WACVW_2025_paper.pdf)
   - 论文：Open-World Hazard Detection and Captioning for Autonomous Driving with a Unified Multimodal Pipeline
   - 一句话总结：论文把开放世界道路危险拆成图像增强、驾驶反应、距离、道路关系与开放词汇字幕五类证据，形成可检查但尚未校准的规则管线。
   - 任务设定：输入约二百段 COOOL 行车记录仪视频，系统逐帧输出驾驶状态、危险框和危险名称，并处理闭集类别外的障碍。各支路调用预训练增强、光流、深度、分割和字幕模型，再由手工阈值与语义规则汇合；论文没有端到端训练损失。
   - 摘要详解：研究问题：自动驾驶中的床垫、动物群或飞行碎片等低频危险不在闭集检测词表内，仅靠异常分数又不能区分“稀有但无害”和“真正侵入行驶空间”。方法与流程：管线先用 NAFNet 改善弱光、噪声和模糊帧，光流支路依据相邻帧角点运动判断驾驶反应；主支路用候选框、MiDaS 相对深度和 SegFormer 道路掩码逐级过滤，再扩框四十像素交给 BLIP 或 grounded captioning，最后按距离、道路关系与字幕语义判定危险并给出名称。全部模块为预训练组件与规则组合，没有端到端训练目标。实验结论：在约二百段 COOOL 行车视频的子集上，MiDaS 加 ViT-L/14 得分 0.43，换 BLIP 为 0.44，加入 grounded captioning 与道路掩码为 0.49；竞赛总分同为 0.49、排名第四，第一名为 0.57。边界：三行配置不是严格逐模块消融，也未报告危险召回、时延或校准，因此结果只支持完整管线可运行，不能证明每个模块分别控制了安全失败。
   - 实验结论：COOOL 子集上三种配置的总分依次为 0.43、0.44、0.49，竞赛排名表中本队也是 0.49、第四名，前三为 0.57、0.51、0.51。作者没有分开报告驾驶状态、危险定位和名称三项得分，也没有候选数量匹配的逐模块消融；因此 0.49 可能部分来自道路掩码减少过预测，而非风险语义更准确。
   - 和我课题的关系：COD：可借“局部外观加环境关系”联合判断目标，但伪装场景没有稳定车道先验，候选器还可能先漏掉前景。UAV：分级增强、几何过滤和语义复核可迁移，微小目标信息丢失与全局相机运动会破坏候选框和原光流规则。火灾：危险应由烟焰证据、距离、增长趋势与字幕共同定义；非刚性半透明烟雾不适合硬框和道路掩码，云雾霾、夕阳及反光还会产生合理的错误字幕。
   - 可借鉴点：最值得借鉴的是把安全失败拆成可审计证据链，而非直接把未知类别塞回闭集分类器。COD 可把道路关系替换为边界连续性和背景可交换性；UAV 可加入稳像、航线和地平面约束；火灾可将 RGB、热像、时序增长和困难负样本证据并列，并为每一级保留中间输出。
   - 可改进点：固定候选框与模型权重，依次替换原帧/NAFNet、单目/真深度、预测/真道路、普通框/实例掩码和 BLIP/grounded captioning，建立配对消融与 oracle 上界。再用单调风险头融合存在性、距离、区域、语义和持续时间，报告固定误报下召回、ECE、预警提前量与最坏天气组。COD、UAV、火灾分别加入空目标、微小模糊目标和云雾霾夕阳反光控制组。
   - 是否值得精读：有条件值得。它提供少见的开放世界危险工程链和三个明确评测公式，适合学习如何拆解安全语义；但方法主要由现成模型和规则拼接，消融、复现细节、实时性和风险校准不足，不能作为可靠性结论的强证据。

3. **Generalizable Single-Source Cross-Modality Medical Image Segmentation via Invariant Causal Mechanisms**
   - Source: WACV 2025, 2025
   - Authors: Boqi Chen, Yuanzhi Zhu, Yunke Ao, Sebastiano Caprara, Reto Sutter et al.
   - Tags: medical imaging, causal/counterfactual, domain generalization, diffusion, representation learning
   - Links: [paper](https://openaccess.thecvf.com/content/WACV2025/html/Chen_Generalizable_Single-Source_Cross-Modality_Medical_Image_Segmentation_via_Invariant_Causal_Mechanisms_WACV_2025_paper.html) / [pdf](https://openaccess.thecvf.com/content/WACV2025/papers/Chen_Generalizable_Single-Source_Cross-Modality_Medical_Image_Segmentation_via_Invariant_Causal_Mechanisms_WACV_2025_paper.pdf)
   - 论文：Generalizable Single-Source Cross-Modality Medical Image Segmentation via Invariant Causal Mechanisms
   - 一句话总结：论文用 DreamBooth、ControlNet 与 Style Swap 构造解剖近似不变而成像风格变化的训练对，再以逐 patch InfoNCE 约束跨模态分割表示。
   - 任务设定：训练仅提供一个源模态的二维带标签切片，测试直接处理训练阶段完全不可见的 CT、MRI 或 X-Ray，不读取目标域无标签图像。输出为器官或椎体分割；扩散模型只在训练期生成干预图，部署时仅运行普通 U-Net。
   - 摘要详解：研究问题：训练只有一种带标签医学模态，测试却要直接分割从未见过的 CT、MRI 或 X-Ray；手工亮度、Bézier 或随机卷积难覆盖真实成像机制变化，单源环境也无法自然暴露稳定因果特征。方法与流程：作者先用 DreamBooth 将 Stable Diffusion 主干适配源医学域，再以分割掩码训练 ControlNet 学习解剖布局；生成时执行 Style Swap，保留控制支路却换回原始扩散主干，并用目标模态词生成“内容近似不变、风格改变”的图像。原图和生成图进入同一 U-Net，在瓶颈对应 patch 上计算 InfoNCE，并与 Dice 分割损失联合优化；推理只运行 U-Net。实验结论：腹部 CT 到 MRI、MRI 到 CT 的平均 Dice 为 86.20、90.17，腰椎两向为 74.93、73.30，肺 CT 到 X-Ray 为 78.79；腰椎去掉 Style Swap 后由 74.93 降至 44.83。论文展示的生成反例还会错误改写后椎弓等细结构。边界：掩码不等于完整生物学内容，生成图可改写细结构，且实验不能证明真实因果机制已被识别。
   - 实验结论：三次随机初始化下，腹部两向平均 Dice 为 86.20/90.17，腰椎为 74.93/73.30，肺 CT 到 X-Ray 为 78.79。腰椎 CT 到 MRI 中，无正则、KL、全局 InfoNCE、逐 patch InfoNCE 分别为 67.47、71.30、70.37、74.93；去掉 Style Swap 降至 44.83。增益支持完整训练顺序和空间对应约束，但不能拆开主干适配与恢复宽风格先验各自的作用。
   - 和我课题的关系：COD：可把目标形状视为内容、背景材质视为风格，但伪装本身依赖前景背景相似；生成器若让前景变显眼就改变了任务。UAV：高度、天气和模糊可作风格干预，几像素目标却可能在扩散生成中直接消失。火灾：烟火非刚性、动态、半透明，外观与语义不可像器官那样干净分离；静态掩码也不能保持增长方向和可见光-热红外响应。
   - 可借鉴点：可迁移的核心是“受控干预对加局部不变性”：让同一空间位置在外观、天气、传感器或模态变化后保持任务表示。COD 可做背景和材质干预；UAV 可把高度、照度、运动模糊作为环境变量，并用框或点热图保护小目标；火灾可用 RGB-T 配对和连续帧区域约束高置信烟焰核心，同时保留边缘不确定性。
   - 可改进点：给生成图加入内容保真门控：源分割器集成、边界距离和拓扑检查共同决定哪些 patch 参与 InfoNCE。用不含 MRI/X-Ray 名称的目标盲提示检验是否依赖已知目标类别，并在等生成数量、等 GPU 小时下比较手工增强、LoRA 扩散和完整流程。COD 测前景背景对比度泄漏，UAV 测目标保留率与 AP_S，火灾测时序增长、固定误报召回及缺失热像风险；内容保留不达标的生成样本不得进入监督。
   - 是否值得精读：值得。论文给出从扩散适配、ControlNet 训练、Style Swap 到逐 patch InfoNCE 的完整链条，式 (1)-(6) 和表 4-6 可核对关键机制。它证明组合方法在三个解剖任务有效，但没有识别真实因果机制，生成细结构错误和目标模态提示依赖仍是主要风险。

4. **RAVU: Retrieval Augmented Video Understanding with Compositional Reasoning over Graph**
   - Source: WACV 2026, 2026
   - Authors: Sameer Malik, Ayush Singh, Moyuru Yamada, Dishank Aggarwal
   - Tags: reasoning, retrieval/prototype, video, compositionality, world model
   - Links: [paper](https://openaccess.thecvf.com/content/WACV2026/html/Malik_RAVU_Retrieval_Augmented_Video_Understanding_with_Compositional_Reasoning_over_Graph_WACV_2026_paper.html) / [pdf](https://openaccess.thecvf.com/content/WACV2026/papers/Malik_RAVU_Retrieval_Augmented_Video_Understanding_with_Compositional_Reasoning_over_Graph_WACV_2026_paper.pdf)
   - 论文：RAVU: Retrieval Augmented Video Understanding with Compositional Reasoning over Graph
   - 一句话总结：RAVU 先把长视频写成可复用的实体-关系-事件图，再把问题编译成组合图操作，仅回看少量证据帧完成零样本问答。
   - 任务设定：输入长视频、自然语言问题和多项选择答案，输出答案及可追踪的检索步骤。系统先离线构建与查询无关的时空图，随后对每个问题零样本分解、检索、重排并调用多模态模型；论文没有任务训练，也没有编号数学公式。
   - 摘要详解：研究问题：长视频问答若均匀采样会漏掉短事件，若把全部帧送入大模型又昂贵且难追踪证据；单次相似度检索还不能回答“某人完成一件事之后做了什么”。方法与流程：RAVU 先用检测与跟踪稳定实体身份，以彩色框提示多模态模型生成逐帧实体、关系和动作描述，再按行为变化切分事件，形成可由多个问题复用的时空图。问答时，语言模型把问题编译为节点定位、前后事件检索和全局行为分析等函数，先用嵌入召回、再语义重排，只把约五个关键帧交给回答模型。论文没有编号数学公式。实验结论：NExT-QA 总体准确率为 74.09，VideoAgent 为 71.3；统一 EgoSchema 基线中 RAVU 为 67.76，CLIP top-10 为 63.88，但约一百八十帧的 All Frames 达 70.67。边界：效率只统计最终输入帧，未计离线构图与多次模型调用；提升可能来自更多测试时计算，而不一定来自图结构本身。
   - 实验结论：NExT-QA 的因果、时间、描述、总体准确率为 76.67/68.91/76.11/74.09，VideoAgent 为 72.7/64.5/81.1/71.3，说明增益集中在因果和时间题，描述题反而下降。统一 EgoSchema 中 RAVU 67.76 高于 CLIP top-10 的 63.88，却低于约一百八十帧 All Frames 的 70.67。人工图 76.65 高于 SAM2 图 74.58，表明自动跟踪和图事实仍限制性能。
   - 和我课题的关系：COD：事件图可检索目标与背景关系的跨帧变化，但 RAVU 假设检测器先找到实体，无法修复伪装前景的候选漏失。UAV：轨迹记忆适合长航拍，微小目标、密集遮挡和相机运动会放大 ID switch，彩色框还可能遮住目标。火灾：初现、增长、漂移和消散适合事件化；烟火没有稳定实例身份，应把对象节点改成区域、流场和热异常簇，并显式处理云雾霾等静态近邻。
