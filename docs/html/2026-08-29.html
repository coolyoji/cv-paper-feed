Toward Low-Cost yet Effective Temporal Learning for UAV Tracking

Source: CVPR 2026, 2026

Authors: Chaocan Xue, Qihua Liang, Bineng Zhong, Yanting Zu, Yuanliang Xue et al.

Tags: video, UAV/small-object, verified full-text deep read

Links: paper / pdf

论文：Toward Low-Cost yet Effective Temporal Learning for UAV Tracking

一句话总结：论文用少量历史 token 的选择与合并获得时间信息，并以每增加一单位 FLOP 带来的精度提升衡量时序模块是否值得。

任务设定：输入是 UAV 跟踪的模板、搜索区域和历史轨迹 token；输出为当前帧目标框。目标是在边缘设备预算下加入时间建模，同时报告精度、FLOPs、参数量和 FPS。

摘要详解：UAV 跟踪中，历史帧能缓解遮挡和外观变化，但常见的动态模板、密集视频或自回归模块会显著增加计算。LETrack 在 DeiT-Tiny 单流架构内提取搜索 token 对模板的注意力/分类分数，保留最相关的 K 个 token 作为历史摘要；新帧到来时，将其中 P 比例与上一时刻最相似的 token 合并，避免保存完整特征序列。作者定义 Precision per FLOP，用精度增量除以新增 FLOPs，作为比较时序策略的统一尺度。UAVTrack112_L 上 AUC 为 68.2，FLOPs 2.48G、参数 7.98M、速度 204 FPS；相对动态模板、密集视频和自回归策略，LETL 的精度增益约 5.0 个点而只增加 0.09G FLOPs，表明稀疏记忆更适合边缘端部署，也便于在低功耗设备上复现。

实验结论：UAVTrack112、UAV123、DTB70、VisDrone；UAVTrack112_L AUC/Precision/FLOPs/Params/FPS 为 68.2/84.8/2.48G/7.98M/204。K=16、保留比例 37.5% 是作者的代表设置。

和我课题的关系：COD 视频化时可借用低成本历史证据，但跟踪的目标连续性不同于静态伪装边界，需单独检验时间一致性是否以牺牲早期发现为代价。

可借鉴点：稀疏历史 token 选择与合并；PPF 作为精度—算力指标。

可改进点：加入光流/帧差和相同历史帧预算的对照，按遮挡、运动模糊和目标尺寸报告时序稳定性；若增益主要来自额外帧而非 token 机制，应收窄贡献。

是否值得精读：值得精读：它把时序收益和计算代价放在同一公式中，适合作为 UAV/COD 边缘部署基线。

NeuroSeg Meets DINOv3: Transferring 2D Self-Supervised Visual Priors to 3D Neuron Segmentation via DINOv3 Initialization

Source: CVPR 2026, 2026

Authors: Yik San Cheng, Runkai Zhao, Weidong Cai

Tags: depth/geometry, self-supervised, verified full-text deep read

Links: paper / pdf

论文：NeuroSeg Meets DINOv3: Transferring 2D Self-Supervised Visual Priors to 3D Neuron Segmentation via DINOv3 Initialization

一句话总结：NeuroSeg 将 DINOv3 的二维视觉先验膨胀到三维编码器，再用骨架拓扑损失约束神经元分支的连通性。

任务设定：输入为带噪声的三维神经影像体数据，输出神经元体素分割及可追踪骨架；假设只有少量三维标注，且细丝结构的拓扑比单纯体素重叠更重要。

摘要详解：三维神经元标注昂贵，普通 Dice/交叉熵又容易漏掉细分支或把相邻分支错误合并。NeuroSeg 用 DINOv3 ConvNeXt 的二维卷积核初始化三维编码器：中心膨胀把核放在深度中心，平均膨胀则沿深度均匀复制；随后接对称 MedNeXt 解码器恢复体素细节。训练在多个尺度同时计算 Dice、交叉熵和 TASL，TASL 将预测与真值骨架转成图，分别惩罚节点位置、边数量和连通分量平均长度差异。四个数据集上 Tiny 版本达到 Drosophila 50.06 F1、NeuroFly 65.23 F1，追踪误差也低于 nnUNet 与 MedNeXt，说明二维语义先验和拓扑约束互补；消融显示去掉拓扑项会先在细分支和连通性上退化。

实验结论：Drosophila、Mouse、NeuroFly、CWMBS；报告 F1、HD95 以及 SmartTracing/NeuTube 的 ESA、DSA、PDS。NeurINOT 在四集分别为 50.06/3.07、52.50/9.50、65.23/16.38、36.77/16.10（F1/HD95）。

和我课题的关系：COD 的困难也常是弱边界导致区域断裂；可迁移的是骨架或边界结构约束，但神经元是细长连通体，不能直接把拓扑等同于伪装目标的真实形状。

可借鉴点：二维自监督权重的维度膨胀；节点—边—路径分解的结构损失。

可改进点：在 COD 上分别加入可微骨架/边界损失与普通分割损失，并按小目标、断裂边界和过分扩张报告 F1、边界 F-score；若拓扑项只改善视觉平滑而不改善结构错误，应否定直接移植。

是否值得精读：值得精读：公式清楚地展示了如何把像素重叠目标改成可测的结构目标。

RoSAMDepth: Robust Self-supervised Depth Estimation Leveraging Segment Anything Model

Source: CVPR 2026, 2026

Authors: Xuanang Gao, Zhiwei Ning, Gengming Zhang, Jiaxi Cao, Runze Yang et al.

Tags: SAM, depth/geometry, self-supervised, verified full-text deep read

Links: paper / pdf

论文：RoSAMDepth: Robust Self-supervised Depth Estimation Leveraging Segment Anything Model

一句话总结：RoSAMDepth 用 SAM 区域把恶劣条件下的自监督深度学习从像素误差判断提升为对象级表示、离群修正与可靠性控制。

任务设定：输入目标帧、相邻单目帧及离线生成的 SAM 非重叠区域，输出目标帧稠密深度；训练不使用深度真值，并假定固定合成教师与光度重投影能提供基础监督。

摘要详解：夜间和雨天会破坏光度一致性，常规边缘平滑又看不到物体内部成片但局部平滑的错误深度。RoSAMDepth 先在解码器多尺度特征上按 SAM 区域构造原型对比损失 SRC，使同区特征聚合、异区特征分离；再由教师区域均值和方差生成 AROM 软离群掩码，并以区域高斯项修正离群位置。ORE 将像素重投影误差汇总成对象可靠性，与离群掩码共同加权教师蒸馏，使错误尺度的整块物体不再因局部偶然匹配而被视为可靠可信。nuScenes 多帧夜间/雨天 AbsRel 达 0.1667/0.1236，作者报告相对 Syn2Real-Depth 跨条件平均改善 AbsRel 2.8%。

实验结论：nuScenes 与 Oxford RobotCar，指标为 AbsRel、SqRel、RMSE、δ1；nuScenes 多帧夜间为 0.1667/1.775/7.729/73.95，雨天为 0.1236/1.521/6.613/83.53。特征级 SRC 优于直接深度约束，AROM 与区域损失也优于图像边缘平滑。

和我课题的关系：COD 可迁移区域原型与对象可靠性，但伪装目标可能根本不被 SAM 分出，且深度的区域同质性不等于前景概率平滑；需用软区域和掩码质量分层验证。

可借鉴点：多尺度区域原型对比学习；区域离群掩码与对象级伪标签重加权

可改进点：用 SAM、超像素、随机面积匹配区域和真值实例掩码做等预算因果对照，并报告边界深度误差及区域内方差；若非语义区域同样有效，就应把贡献改写为区域正则化而非 SAM 语义先验。

是否值得精读：值得精读：它提供了从区域统计到对象级可靠性蒸馏的完整公式链，但 SAM 语义的独立贡献仍未证实。

PanDA: Unsupervised Domain Adaptation for Multimodal 3D Panoptic Segmentation in Autonomous Driving

Source: CVPR 2026, 2026

Authors: Yining Pan, Shijie Li, Yuchen Wu, Xulei Yang, Na Zhao

Tags: unsupervised, depth/geometry, domain adaptation, verified full-text deep read

Links: paper / pdf

论文：PanDA: Unsupervised Domain Adaptation for Multimodal 3D Panoptic Segmentation in Autonomous Driving

一句话总结：PanDA 用结构化模态缺失增强和几何—视觉双专家修补伪标签，解决跨天气、地点和传感器域迁移中的实例断裂。

任务设定：输入源域有标注的相机图像与 LiDAR 点云、目标域无标注的配对数据，输出目标域 3D 全景语义和实例标签；假设两种模态仍可配准但质量会下降。

摘要详解：多模态全景分割的域迁移同时受目标域无标注、模态退化和伪标签碎片化影响。PanDA 采用 EMA mean-teacher：源域用真值，目标域用教师预测。AMD 在图像 Canny 边界或实例内部、以及 LiDAR 几何不连续处做非对称随机丢弃，并用源域语义辅助头恢复被遮区域。DualRefine 先按置信度筛选 stuff/thing 伪标签，再以 RANSAC+HDBSCAN 得到几何 superpoint 补全 stuff 区域，最后将 Grounding DINO+SAM 的二维 mask 提升到三维，用视觉 superpoint 在低置信实例上重分配类别。USA→Singapore、Sunny→Rainy、Day→Night、SemanticKITTI→nuScenes 的最终 PQ 为 77.3、72.4、73.1、54.5，较基线分别提升 13.2、8.9、8.4、53.3；作者的消融将补全收益归因于 DualRefine，将退化鲁棒性归因于 AMD，并强调两者互补，且不同域移位的收益并不相同，不能用单一平均数概括。

实验结论：nuScenes 三种域移位及 SemanticKITTI→nuScenes；主指标 PQ，并拆分 PQth/PQst。组件消融表明 DualRefine 主要补全，AMD 主要提高跨模态鲁棒性。

和我课题的关系：COD 可把‘区域碎片化’视为伪装 mask 的核心失效，并借用结构化遮挡增强；但 LiDAR 几何 superpoint 在二维伪装场景没有同等可靠性。

可借鉴点：按边界/实例语义设计的模态缺失增强；几何先补全、视觉后改类的双专家伪标签流程。

可改进点：在 COD 跨数据集迁移中控制随机遮挡与真实雾霾两类退化，分别测 mask 完整率、PQ 类指标和目标缺失误报；若双专家只在有高质量外部 mask 时有效，应报告依赖边界。

是否值得精读：值得精读：它把伪标签错误拆成完整性和类别两种可诊断故障。

Detecting Unknown Objects via Energy-based Separation for Open World Object Detection

Source: CVPR 2026, 2026

Authors: Jun-Woo Heo, Keonhee Park, Gyeong-Moon Park

Tags: open-world, verified full-text deep read

Links: paper / pdf

论文：Detecting Unknown Objects via Energy-based Separation for Open World Object Detection

一句话总结：DEUS 用固定 Simplex ETF 把已知与未知 proposal 放进两块子空间，以能量间隔发现未知、以旧新头能量排序缓解增量遗忘。

任务设定：输入按任务递增的图像、真值框和 RoI proposal；输出已知类别框、unknown 框及背景。未知类没有真值，只能从未匹配 proposal 产生伪标签，增量阶段还要用 memory replay 保留旧类。

摘要详解：开放世界检测若只依赖已知分类分数，未知物体会和背景混淆，未匹配框的噪声还会污染训练。DEUS 从 OrthogonalDet proposal 特征出发，用 Simplex ETF 的前后半固定基构造已知、未知子空间；式(7)(8)分别计算两块能量，式(11)对真值已知和伪未知施加相反方向的 margin，式(12)再以二元 focal 稳定背景边界。推理时将标准化能量差加入 unknown logit（式(14)）。回放阶段 EKD 用旧头/当前头的 log-sum-exp 排序减少交叉干扰。M-OWODB 任务1未知召回/H-score为65.1/65.6，RS-OWODB任务1为58.1/62.5，作者同时报告较低额外开销；语义重叠和伪标签噪声仍是边界，说明能量间隔不是对所有未知类别都可靠。

实验结论：M-OWODB、S-OWODB、RS-OWODB；指标为 current/previous/known mAP、U-Rec 与 H-Score。M-OWODB DEUS 任务1/2/3 U-Rec 为 65.1/66.2/69.0；RS-OWODB 任务1 known mAP/U-Rec/H 为 67.7/58.1/62.5，较 OrthogonalDet 的 65.4/23.7/34.8。

和我课题的关系：COD 可把能量差当作‘前景但类别未知’的拒识信号，用来分离伪装区域与背景；但 OWOD 的框级伪未知不能直接替代 COD 的像素级 mask，且 UAV 小目标的信息损失和火烟的时间演化需要额外建模。

可借鉴点：固定已知/未知子空间与可校准能量差；回放阶段旧头/当前头的能量排序约束

可改进点：用固定 ETF、随机冻结基和同参数量可学习正交基做对照，并在 COD/UAV/火灾开放集测试报告 AUROC、FPR95、风险覆盖和早期召回；若增益随伪标签清洁化消失，说明核心依赖伪标签噪声而非 ETF 几何。

是否值得精读：值得精读：式(4)-(17)把未知分离、推理校准和增量保持串成可审计的能量链，但各组成因果贡献仍需更强对照。
