Towards Zero-Shot Anomaly Detection and Reasoning with Multimodal Large Language Models

Source: CVPR 2025, 2025

Authors: Jiacong Xu, Shao-Yuan Lo, Bardia Safaei, Vishal M. Patel, Isht Dwivedi

Tags: VLM/MLLM, reasoning, anomaly/OOD, verified full-text deep read

Links: paper / pdf

论文：Towards Zero-Shot Anomaly Detection and Reasoning with Multimodal Large Language Models

一句话总结：通用多模态模型会忽略细粒度缺陷，论文用异常专家先筛选可疑视觉词元，再让语言模型围绕这些证据完成零样本检测与解释。

任务设定：输入是无目标类训练样本假设下的高分辨率图像与问题，输出异常判断、位置描述和原因建议；训练使用跨工业、医学、三维和自然图像的指令数据，测试覆盖九个零样本异常数据集及 VisA-D&R。

摘要详解：论文先构建 Anomaly-Instruct-125k 与 VisA-D&R，指出 GPT-4o 等通用模型能看见图像却常漏掉细小缺陷或给出错误解释。Anomaly-OV 以 LLaVA-OneVision 为底座，在四层视觉特征上用 Look-Twice Feature Matching 生成对象条件的正常/异常描述，再由 Visual Token Selector 用显著图池化并经 Q-Former 聚合可疑词元，插入 LLM 生成问答。异常专家在九个数据集平均 AUROC 为 88.6，VisA-D&R 的 7B 模型检测 F1 为 0.83；作者同时报告专家、数据偏差和跨域基准不足。其关键边界是无目标类样本不等于无训练数据，WebAD 和人工复核仍提供了丰富先验；异常分数还会决定提示强度，专家定位错误可能直接传导到语言解释。

实验结论：九个零样本数据集平均 AUROC 88.6；MVTec/VisA 为 94.0/91.1。VisA-D&R 上 0.5B/7B 检测 F1 为 0.82/0.83，去掉 WebAD 后 MVTec AUROC 降至 88.5。

和我课题的关系：可把对象条件的可疑词元筛选迁移到 COD 的难分前景区域，但异常与伪装前景的语义方向不同；UAV 还需尺度和运动上下文，火灾需时序与可见-热融合。

可借鉴点：多层异常显著性驱动的 token 选择；把检测分数转成语言模型的证据强度提示。

可改进点：在同等 token 数和数据预算下加入随机选择对照，并用人工 mask、ECE、PRO 和跨域误报评估；若随机选择相当，说明增益主要来自微调而非专家机制。

是否值得精读：值得精读：视觉筛选与语言解释的接口清晰，但 WebAD 自动标注和工业域测试使机制归因与安全泛化仍未充分验证。

SARMAE: Masked Autoencoder for SAR Representation Learning

Source: CVPR 2026, 2026

Authors: Danxu Liu, Di Wang, Hebaixu Wang, Haoyang Chen, Wentao Jiang et al.

Tags: remote sensing, representation learning, verified full-text deep read

Links: paper / pdf

论文：SARMAE: Masked Autoencoder for SAR Representation Learning

一句话总结：SAR 的数据稀缺、斑点噪声和语义不足互相叠加，论文用物理噪声去噪重构与配对光学语义锚共同预训练 ViT。

任务设定：输入是无标签 SAR 图像，部分带地理配准光学图像；输出是可迁移到分类、水平/旋转检测和分割的 SAR 编码器。预训练使用 18 个公开数据集组成的 SAR-1M，推理和下游部署只需 SAR 模态。

摘要详解：论文构建 1.3M 规模的 SAR-1M，并针对普通 MAE 忽略 SAR 斑点统计的问题提出 SARE：按 Gamma 等物理噪声模型扰动输入，却要求解码器重构原始 patch。对有配准光学图像的样本，冻结 DINOv3 提取同位置特征，SARC 以低权重余弦距离约束 SAR 表征的语义方向。SARMAE 在 FUSAR、MSTAR、SARDet-100k、RSAR 和 AIR-PolSAR-Seg 上覆盖分类、检测、分割，ViT-B 在 FUSAR 30% 标注达 92.92% 准确率，SSDD 检测 mAP 68.10%。其边界是配准质量、合成噪声与大规模域内数据的共同影响仍需拆分；光学图只在预训练作教师，部署时仍是单模态 SAR，因此不能把测试期多模态输入的收益算入本方法，还需验证跨传感器稳定性。

实验结论：FUSAR 30% 标注分类 92.92%，SARDet-100k/SSDD/RSAR mAP 为 57.90/68.10/66.80；SARE 使 FUSAR 从 82.22 升至 86.80，SARC 再升至 89.30。

和我课题的关系：可将物理扰动重构迁移为 COD 的伪装不变性学习，并将跨模态语义锚用于 UAV 可见-热融合和火灾早期证据；但 SAR speckle、COD 相似背景和火灾动态透明性并不等价。

可借鉴点：保持目标不变的领域特定扰动重构；低权重同位置跨模态语义对齐。

可改进点：按传感器/地区留出并施加配准误差、真实噪声和无配对比例控制，联合报告 mAP、边界指标和校准误差；否则难以区分规模、噪声模型与跨模态约束的贡献。

是否值得精读：值得精读：物理先验到预训练目标的映射具体且可迁移，但合成噪声和配对光学锚的外部有效性仍需严格压力测试。

SPA: Efficient User-Preference Alignment against Uncertainty in Medical Image Segmentation

Source: ICCV 2025, 2025

Authors: Jiayuan Zhu, Junde Wu, Cheng Ouyang, Konstantinos Kamnitsas, J. Alison Noble

Tags: uncertainty/calibration, medical imaging, verified full-text deep read

Links: paper / pdf

论文：SPA: Efficient User-Preference Alignment against Uncertainty in Medical Image Segmentation

一句话总结：SPA 将多标注者边界歧义表示为可更新的混合高斯，用四个代表性掩码把高交互成本改成少轮多选偏好对齐。

任务设定：输入单张医学图像、初始点提示和用户逐轮选择，输出符合该用户标注偏好的分割掩码；训练利用多标注者掩码，测试不要求真实用户标签。

摘要详解：论文针对医学分割中成像噪声与标注偏好共同造成的边界不确定性，强调同一像素在诊断和放疗语境下可能有相反取舍。SPA 用混合高斯潜变量采样多个候选，平均得到推荐掩码，再以 K-means 压成四个差异明显的代表候选，用户只需多选。被选掩码经 SAM 交互编码器进入偏好分布生成器，更新均值、方差和混合权重后重新采样，逐轮贴近用户语境。作者在 REFUGE2、LIDC-IDRI、QUBIQ 多任务上报告三轮平均 Dice 89.68%，人机研究称迭代减少约 39%，并观察到候选先分化再收敛，边界差异逐轮缩小。

实验结论：REFUGE2、LIDC-IDRI、QUBIQ 七项任务；三轮平均 Dice 89.68%，LIDC 相对既有方法约提升 20 个百分点。REFUGE2 达到 87% Dice 少于五轮，LIDC 达到 75% 约 2.7 轮；五名专业人员在 100 张眼底图上用时约 4.34–4.77 秒/图，MedSAM 约 6.62–8.04 秒/图。消融中 REFUGE2/Kidney 三轮 Dice 从随机采样的 80.29%/90.05% 升至完整模型的 85.42%/94.26%。

和我课题的关系：可把 COD 的边界争议转成可交互的多峰偏好，但 COD 通常没有多医生式偏好标签，而伪装前景背景相似也不同于医学中的风险取舍。

可借鉴点：用潜变量混合分布保留多个合理边界，再用代表性候选而非全部样本承载不确定性。；把用户选择编码为状态并更新分布参数，显式区分候选生成与偏好校准。

可改进点：最大风险是合成标注选择规则代替了真实医生决策。应做盲法多中心用户实验，并在同等 48 样本预算下比较固定集成器与在线更新，报告边界 Hausdorff、漏分割/外扩代价和时间；若固定集成器相当，说明分布更新的因果作用不足。

是否值得精读：值得精读：统计偏好建模、候选压缩和在线反馈形成了完整闭环，但真实临床风险与有限反馈收敛仍需独立验证。

Feature Information Driven Position Gaussian Distribution Estimation for Tiny Object Detection

Source: CVPR 2025, 2025

Authors: Jinghao Bian, Mingtao Feng, Weisheng Dong, Fangfang Wu, Jianqiao Luo et al.

Tags: UAV/small-object, verified full-text deep read

Links: paper / pdf

论文：Feature Information Driven Position Gaussian Distribution Estimation for Tiny Object Detection

一句话总结：下采样让极小目标的像素证据消失，本文用概率编码代价找出信息损失区域，再用尺度感知的位置高斯图校准 P2 特征。

任务设定：输入航拍或遥感图像，输出目标类别与边界框；重点处理 2–32 像素目标，假设训练时有框标注，推理时只有图像。

摘要详解：论文针对 FPN 下采样后极小目标与背景混淆的问题，认为仅靠尺度融合或启发式注意力难以知道哪些位置真正丢失了像素证据。方法先把 P2 特征加入可微量化和高斯密度估计，以信息熵损失得到高信息量区域的尺度图；再由目标框中心、宽高和尺寸类别构造高斯混合的位置分布图，把它作为 P2、P3、P4 的多尺度监督，并分别增强 P2 后经 CBAM 融合。作者在 VisDrone2019、AI-TOD、AI-TODv2 上验证，DetectoRS 在 VisDrone 达到 24.3 AP，AI-TODv2 达到 25.5 AP，极小目标指标也提升；但信息量等同显著性、固定协方差规则和端侧成本仍需单独验证。

实验结论：在 VisDrone2019、AI-TOD、AI-TODv2 上，DetectoRS 接入完整模块后分别报告 VisDrone 24.3 AP、AI-TOD 24.3 AP、AI-TODv2 25.5 AP；VisDrone 的 APvt 为 8.5。消融中像素信息建模、位置分布预测单独和联合 AP 为 28.2、27.6、28.3（基线 26.3），说明互补但不等于独立因果。

和我课题的关系：对 UAV 是直接的小目标迁移，对 COD 可把信息图当作可疑差异先验；但 COD 的目标边界不服从框高斯，火灾的烟雾还具有动态、半透明和非刚体证据。

可借鉴点：借鉴概率编码代价定位弱证据区域；借鉴按目标尺度调整协方差并用平滑分布监督，而非单点中心标签。

可改进点：最强风险是纹理、压缩伪影或烟雾也会产生高编码代价。用硬负样本分层校准信息图与真实目标重叠，并以可学习协方差替换固定 α；若误报仍不降，说明信息量假设不足。

是否值得精读：值得精读：它把无监督信息量估计与有监督位置分布结合到 P2，适合作为 COD/UAV 弱证据增强的可复现实验基线。

Pseudo Visible Feature Fine-Grained Fusion for Thermal Object Detection

Source: CVPR 2025, 2025

Authors: Ting Li, Mao Ye, Tianwen Wu, Nianxin Li, Shuaifeng Li et al.

Tags: computer vision, verified full-text deep read

Links: paper / pdf

论文：Pseudo Visible Feature Fine-Grained Fusion for Thermal Object Detection

一句话总结：PFGF 不盲信热到可见生成图，而是用图节点、Inter-Mamba 和级联 leader node 在多尺度上筛选并传播有用的伪可见关系。

任务设定：训练可用带标签热图和未配对可见图，测试只输入热图；输出行人、车辆等目标框和类别，内部由 Pearl-GAN 生成伪可见图与潜特征。

摘要详解：论文针对热红外纹理不足与伪可见翻译噪声并存的问题，指出直接拼接生成图会把遮挡和幻觉纹理传给检测器。Pearl-GAN 从热图生成可见图和潜代码，CSPDarknet 与 VMamba 提取多层判别特征；PFGF 把这些特征拆成多粒度图节点，在最低层用 Inter-Mamba 以热分支门控伪可见信息，再通过 CKI 和 leader node 从低层向高层传播。消息传递迭代后，各层残差特征进入 YOLOX 检测头，并始终只需热图输入。FLIR、LLVIP、AV 上 mAP 分别达 47.1、67.3、45.9，显示关系筛选优于无条件融合，并在不同融合基线和 Transformer 替代实验中保持优势；作者还用 leader node 可视化显示误检减少。

实验结论：FLIR mAP50/mAP75/mAP 为 84.8/44.6/47.1，超过 TIRDet 的 81.4/41.1/44.3；LLVIP PFGF* 为 96.9/78.4/67.3；AV 为 78.8/46.6/45.9。去掉 Pearl-GAN、MEM、GMF 后 mAP 分别降至 FLIR 45.2、46.0、45.6，GMF 去掉 Inter-Mamba/CKI 为 45.9/46.1。GMF 比加法、拼接和多种融合策略更高；替换为 Transformer 后 FLIR mAP 46.2、FLOPs 604.1G。

和我课题的关系：可把伪可见支路视为 COD 的候选外观证据并用门控筛噪，但生成纹理可能制造背景目标，且 COD 没有真实跨模态互补保证。

可借鉴点：将不可靠辅助模态拆成多尺度节点，以关系边和输入分支门筛掉冗余信息。；用低层已筛选摘要逐级传给高层，避免所有辅助特征无条件直连检测头。

可改进点：论文未报告生成质量与检测收益的相关性，也缺少等参数 FPN/GNN 对照。应加入真实、伪造、随机颜色化和零辅助特征的等容量实验，并按雾天、遮挡和生成失败分层报告误报与校准；若随机辅助也同样有效，图关系的因果解释不成立。

是否值得精读：值得精读：它把跨模态融合重写为有噪声关系筛选问题，公式和消融清楚，但真实域迁移、生成失败和端侧成本仍待验证。
