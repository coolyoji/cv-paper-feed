摘要详解：研究问题：开放世界无人机目标导航既要记住已观测目标，又要判断下一步该探索哪里；仅使用当前视野或平面稠密地图容易遗忘远处结构，并在大场景浪费计算。方法与流程：OctMem-Agent把RGB-D与位姿反投影为三维点，按距离以不同粒度增量写入Adaptive Octree Memory；该树只保存已观测场景，并不显式构建几何frontier。Instruction-Guided Memory Query以目标描述经FiLM调制场景查询与探索查询，分别读取近场目标证据和远场已观测上下文，再与当前图像、语言共同输入OpenVLA式动作解码器。实验结论：在纯仿真的UAV-ON上，总SR从OpenFly的12.00%升至19.50%，OSR为29.30%、SPL为6.37%；未见环境SR为17.57%，但SPL仅5.15%。消融中单加八叉树的SR为15.70%，再加指令查询才到19.50%，支持两模块互补而非单纯扩大内存。迁移边界：可将层级近远场记忆和指令查询用于持续COD、UAV巡检及火情搜索，但真实部署必须单独检验深度/位姿噪声、运动模糊与弱小目标遗忘。
